FELIX HARREN – VERÖFFENTLICHUNGSPAKET

GitHub-Konto:
FullBlogg

Empfohlener Repository-Name:
FullBlogg.github.io

Endgültige Domain:
felixharren.de

Dieses Paket ist für die Veröffentlichung vorbereitet.

ENTHALTEN:
- CNAME für felixharren.de
- .nojekyll für die statische Website
- sitemap.xml
- robots.txt mit Sitemap-Adresse
- Canonical-Links für alle Seiten
- Open-Graph-Adressen mit vollständiger Domain
- strukturierte Daten mit Website-Adresse
- eigene 404-Seite
- keine sichtbaren Beispieltermine

WICHTIG:
Die früheren Beispieltermine wurden aus der öffentlichen Terminliste
entfernt. In termine-daten.js befindet sich weiterhin eine kommentierte
Vorlage für echte Termine.

GITHUB:
1. Auf GitHub ein öffentliches Repository namens
   FullBlogg.github.io erstellen.
2. Den vollständigen Inhalt dieses Ordners hochladen.
3. Unter Settings > Pages als Quelle „Deploy from a branch“ auswählen.
4. Branch „main“ und Ordner „/(root)“ auswählen.
5. Anschließend unter Custom domain „felixharren.de“ eintragen.
6. Erst danach die DNS-Einträge bei Wix ändern.

Nicht den übergeordneten Ordner hochladen, sondern dessen Inhalt:
index.html, style.css, bilder/, CNAME usw. müssen direkt im
Stamm des Repositorys liegen.
